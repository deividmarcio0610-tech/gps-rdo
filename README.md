# GPS-RDO

Relatório Diário de Obra (RDO) para celular: cabeçalho, mão de obra, equipamentos, tarefas,
ocorrências, horas paradas, fotos com data, hora e GPS, PDF com as fotos e resumo do mês.

## Instalar

**Link do app:** https://deividmarcio0610-tech.github.io/gps-rdo/

- **Android:** abra o link no Chrome e toque em **Baixar o app Android (APK)**, ou baixe direto:
  https://github.com/deividmarcio0610-tech/gps-rdo/releases/latest/download/GPS-RDO.apk
  Abra o arquivo baixado e permita "instalar apps desconhecidos" para o app que abriu o arquivo.
  Instala por cima da versão anterior sem perder os RDOs.
- **iPhone:** abra o link no **Safari** e toque em **Compartilhar** (quadrado com seta) >
  **Adicionar à Tela de Início** > **Adicionar**. O iPhone não instala app por arquivo; assim o
  GPS-RDO fica com ícone, em tela cheia, e funciona sem internet.

Depois da primeira abertura funciona sem internet. Os relatórios ficam guardados só no próprio
celular: nada é enviado para este site. Use **Cópia de Segurança** para não perder nada ao trocar
de celular.

Esta é a cópia publicada do app (HTML, CSS e JavaScript). jsPDF e jspdf-autotable sob licença MIT.
O APK é assinado com chave de teste (debug): serve para instalar direto, não para a Play Store.
