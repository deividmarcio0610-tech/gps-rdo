# GPS-RDO

Relatório Diário de Obra (RDO) para celular: cabeçalho, mão de obra, equipamentos, tarefas,
ocorrências, fotos com data, hora e GPS, PDF e resumo para WhatsApp.

**Abrir:** https://deividmarcio0610-tech.github.io/gps-rdo/

- **iPhone:** abra o link no Safari > Compartilhar > Adicionar à Tela de Início.
- **Android:** abra no Chrome > menu > Instalar aplicativo (ou Adicionar à tela inicial).

Depois da primeira abertura funciona sem internet. Os relatórios ficam guardados só no próprio
celular: nada é enviado para este site.

Esta pasta é só a cópia publicada do app (HTML, CSS e JavaScript). jsPDF e jspdf-autotable sob
licença MIT.
